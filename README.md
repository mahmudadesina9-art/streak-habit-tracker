# 🔥 Streak — Daily Habit Tracker

Streak is a simple mobile-first habit tracker built as part of my 100-Day Coding Challenge.

The idea is simple: code every day, build your streak, and stay consistent.

## 🎯 Why I Built This

I wanted to build something that encourages me to code every day.

When I see that I have a streak to maintain but haven't coded for the day, it gives me a reason to get up, start coding, and keep the streak alive.

## ✨ Features

- Track a daily coding habit
- Maintain a coding streak
- Save streak data using Local Storage
- Keep a history of completed days
- Display weekly activity
- Prevent completing the same day twice
- Reset streak and history
- Share your current streak
- Mobile-first interface

## 🛠️ Technologies

- HTML
- CSS
- JavaScript
- Local Storage
- Web Share API

## 🧠 Biggest Challenges

The hardest parts of this project were:

- Calculating and updating the streak count
- Working with dates
- Building the weekly activity section
- Making sure the streak behaves correctly when a day is missed
